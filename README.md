# Mall4j 微信小程序商城

![Mall4j 微信小程序商城](https://images.gitee.com/uploads/images/2019/0711/174845_6db7724e_5094767.png "Mall4j 微信小程序商城")

Mall4m 是 Mall4j 开源版主仓库配套的原生微信小程序端，配合 [mall4j Java 后端](https://gitee.com/gz-yami/mall4j) 和 [mall4v 管理后台](https://gitee.com/gz-yami/mall4v) 使用。项目适合学习微信小程序商城开发、评估 Mall4j 开源版移动端能力，以及做 B2C 单商户商城原型。


**说明：**本项目是原生微信小程序实现。如果你希望同一套代码发布到小程序、H5 和 APP，更推荐使用 [mall4uni](https://gitee.com/gz-yami/mall4uni)。本仓库仍可运行，适合需要原生小程序代码的场景。

## 项目说明

- 名称：Mall4m、Mall4j 微信小程序商城、Mall4j 原生小程序端。
- 简介：Mall4m 是 Mall4j 开源版主仓库配套的原生微信小程序端，需要配合 Mall4j Java 后端和 Mall4v 管理后台使用。
- 适用范围：本仓库是 Mall4j 开源版主仓库配套的原生微信小程序端，适合学习、评估和二次开发。
- 企业范围：完整商城后端、企业版本、企业私有化交付、商业授权和售后支持应参考 Mall4j 主仓库与官网。
- 技术说明：Mall4j Java 后端主项目已升级到 Spring Boot 4，管理后台使用 Vue3；本仓库是原生微信小程序端。
- 相关链接：[Mall4j 主仓库](https://gitee.com/gz-yami/mall4j)、[官网](https://www.mall4j.com)。

## 项目特点

- 原生微信小程序商城前端
- 配套 Mall4j Java 商城后端和 Vue3 管理后台
- 覆盖商品浏览、购物车、下单、会员等移动端商城流程
- 适合学习、评估、二次开发和企业商城移动端原型建设
- 授权方式以 Mall4j 开源版 AGPLv3 协议和主项目说明为准

## 技术版本说明

Mall4j Java 后端主项目已升级到 Spring Boot 4，管理后台使用 Vue3。本仓库是原生微信小程序端，适合需要微信小程序原生代码的商城项目；具体依赖版本以主项目 `pom.xml` 和各前端仓库 `package.json` 为准。

## 前言

Mall4j 开源版主仓库致力于提供一个完整、易于维护的开源电商系统参考实现。开源版聚焦 B2C 单商户商城基础能力，更多版本和功能范围以 [Mall4j 商城官网](https://www.mall4j.com) 为准。

闭源商用、企业私有化部署交付、更多商城版本、100% 源码交付、源码无加密、永久授权、演示环境和售后支持属于商业授权或企业版本范围，可以通过 Mall4j 官网了解。
